#Create a Telephony inline hook in your Okta account

Activate the telephony inline hook in your Okta org. Activating the telephony inline hook registers the hook with the Okta org and associates it with your external service.

Log in to your Okta administrator account and navigate to the Admin Console.

* Go to the Workflow > Inline Hooks page
* Click 'Add Inline Hook' and select Telephony from the dropdown list

Enter a name for the hook (e.g RingCentral SMS Hook)
Copy the URL provided from this app and paste onto the URL field
Copy the value from the Authentication field provided from this app and paste it into the Authentication field
Copy the value from the Authentication secret provided from this app and paste it into the Authentication secret
Click Save to save the inline hook
